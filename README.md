# The Last Lap

Web educativa e interactiva sobre una misión hipotética a Marte que usa la Luna como honda gravitatoria.

Abre `index.html` en el navegador para verla.

Fotos: Tierra (Apollo 17, NASA), Luna (Lunar Reconnaissance Orbiter, NASA) y Marte (telescopio espacial Hubble, NASA), de dominio público.
